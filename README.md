# Pima Indians Diabetes - Exploratory Data Analysis (EDA)
## Overview
This project performs exploratory data analysis on the Pima Indians Diabetes dataset to understand relationships between clinical variables and diabetes outcome.

## Dataset
The dataset contains medical diagnostic data for female patients of Pima Indian heritage, including glucose levels, BMI, insulin, blood pressure, and age.

## Objectives
- Understand distribution of key clinical variables
- Identify outliers using clinical thresholds
- Explore relationships between features and diabetes outcome
- Visualize patterns in the dataset
